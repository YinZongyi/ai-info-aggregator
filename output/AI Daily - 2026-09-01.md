- **来源**：GitHub Trending
- **评分**：8/10
- **标签**：`#GitNexus` `#知识图谱` `#代码分析` `#RAG` `#开源工具`
- **摘要**：GitNexus 是一款零服务器、完全运行在浏览器中的代码智能引擎，支持导入 GitHub、GitLab、Azure 及本地 Git 仓库或 ZIP 文件，自动将代码库索引为包含依赖、调用链和聚类的交互式知识图谱，并内置 Graph RAG Agent 供代码探索。相比 DeepWiki 仅“理解”代码，GitNexus 通过 CLI 和 MCP 工具（`npx gitnexus analyze` 一键索引并生成 AGENTS.md/CLAUDE.md，`npx gitnexus setup` 自动配置 Cursor、Claude Code、Codex 等编辑器）为 AI 智能体提供完整的架构级上下文，使小模型也能获得架构级清晰度，避免遗漏依赖或破坏调用链。项目已发布至 npm，并提供 Web UI 及企业版 SaaS/自托管服务，但明确声明无任何官方加密货币或代币。
