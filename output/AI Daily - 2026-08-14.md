- **摘要**：diff-rationale 是一个开源的 CLI 工具（GitHub: cameron-mcateer/diff-rationale），通过 git 为每次 Claude 提交的变更分块记录 rationale，并在变更合入受保护分支后“mint”成逐行解释日志，存入独立 git ref，避免污染工作区，支持后续按文件任意位置查询修改原因。它还提供 interview 模式，可基于自定义 schema 提问并自动暂存用户回答，主要用于编码 agent 场景，并附带一个可选的 VS Code 插件用于可视化记录。
