## AI工具实操/Agent工作流

### [pacifio/atlas](https://github.com/pacifio/atlas)
- **来源**：GitHub Trending
- **评分**：7/10
- **标签**：`#开源项目` `#Coding Agent` `#多Agent协同` `#开发者工具` `#版本控制`
- **摘要**：Atlas 是面向编码智能体的源代码管理工具，将每次 agent 运行产生的 commit 与对应会话的 prompt、工具调用和推理过程绑定为 checkpoint，便于事后查询"哪个 agent 做了什么、为什么做"。它支持 Claude Code、Codex、Atlas 自带 agent 及 ACP registry 中的其他 agent 在同一代码库上并行运行，并通过共享内存让任务中途切换 agent 无需重来。项目以 Rust 编写、MIT 协议、目前面向 macOS，官网为 tryatlas.cc。
