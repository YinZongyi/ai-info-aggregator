### [Show HN: Grist, open source coding harness](https://grist.lol/)
- **来源**：Hacker News Show HN
- **评分**：5/10
- **标签**：`#AI Agent` `#开源项目` `#模型路由` `#CLI工具`
- **摘要**：Grist 是基于 Opencode v2 构建的开源编码 harness，通过 jev 决策模型把任务分为 easy/medium/hard/frontier 四档并路由到 DeepSeek 等廉价模型或 Opus 5.5，再叠加 Sol-Pi 方法（action fusion + observation packing）压缩各档 token 消耗，并用 Doctrine injection 将团队工程规范默认注入每次会话。它提供升级、权限与验证钩子组成的控制平面，使用 OpenRouter 或 Vercel AI gateway 的单一 key 即可调用决策模型与编码 LLM，还可接入 Meta Muse 执行编码任务。现有 Mac 应用和 CLI 两种使用方式，CLI 安装命令为 `npm install -g grist-ai`。
