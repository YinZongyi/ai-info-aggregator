### [Using Blender with coding agents on macOS](https://simonwillison.net/2026/Sep/5/blender-coding-agents-macos/)
- **来源**：Simon Willison's Blog
- **评分**：7/10
- **标签**：`#Blender` `#coding agents` `#ChatGPT Codex` `#3D生成`
- **摘要**：在 macOS 上使用 ChatGPT Codex 调用 Blender 非常简便：先从 blender.org 安装完整版 Mac 应用，然后直接输入 prompt 如“Use the already install /Applications/Blender to render a scene of a pelican riding a bicycle”，再后续追加“OK add a background and a lot of flair”和“OK make it a whole lot better”即可迭代生成效果。整个过程通过 Blender 的 Python API 自动完成，最终产出一张鹈鹕骑自行车的 3D 场景图。

### [The Pelican comparison grid for Astra is pretty interesting](https://simonwillison.net/2026/Sep/4/astra-pelicans/)
- **来源**：Simon Willison's Blog
- **评分**：8/10
- **标签**：`#GPT-6 Astra` `#模型对比` `#图像生成` `#成本分析`
- **摘要**：在鹈鹕骑自行车的SVG生成对比中，GPT-6 Astra（支持low至max推理级别）的图像质量全面超越GPT-5.6 Sol/Terra/Luna：Astra最差的low级别输出仍优于Sol所有级别的最佳结果，且仅需9.55美分；而Astra定价为$10/百万输入tokens与$50/百万输出tokens（Sol为$5/$30），但其各推理级别token消耗显著更低，实际价差小于标价。此外，Astra与Luna均只使用16个输入tokens，Sol与Terra为26个，暗示两者可能存在更深层关联。
