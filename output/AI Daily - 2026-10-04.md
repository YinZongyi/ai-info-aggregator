### [I built a lifting tracker that is actually easy to use](https://www.reddit.com/r/SideProject/comments/1wwz6z8/i_built_a_lifting_tracker_that_is_actually_easy/)
- **来源**：Reddit r/SideProject
- **评分**：5/10
- **标签**：`#独立开发` `#一人公司` `#AI辅助开发` `#Side Project` `#健身App`
- **摘要**：数据工程师用 AI 生成 UI、自己负责数据库部分，做出一款名为 GYM 的力量训练记录 App，核心是"少即是多"：重量和次数自动沿用上一组，改一下点 Add Set 即可完成记录，只有当前重量达到目标次数后才允许加重，并按 Upper/Lower、PPL 等计划自动轮转当日训练，同时内置休息计时器、杠铃片计算器和进度图表。该 App 免费、无账号、无广告、完全离线、数据只存手机本地，目前为 beta 版未上架应用商店，Android 7.0+ 用户可从 GitHub Pages 直接下载安装包，或把 GitHub 仓库添加到 Obtainium 实现自动更新。

## AI工具实操/Agent工作流

### [google/skills](https://github.com/google/skills)
- **来源**：GitHub Trending
- **评分**：7/10
- **标签**：`#Agent Skills` `#Google Cloud` `#开源项目` `#AI Agent`
- **摘要**：Google 官方 skills 仓库汇集了面向 Google Cloud 等产品的 Agent Skills，涵盖云认证与入门（google-cloud-recipe-auth、onboarding、foundation-builder）、多产品方案（AlloyDB 动态混合搜索、GKE 推理迁移、GKE+AlloyDB 企业搜索 RAG、Agent Gateway 多智能体安全、无边界开放数据湖仓智能分析）以及 AI/ML 等类别。安装方式为执行 `npx skills add google/skills`，随后在 `npx install` 交互流程中勾选需要安装的具体 skill；仓库内还提供 Google Skill Finder 用于检索可用技能。
